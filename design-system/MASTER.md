# Wachoo design system

## Product and design direction

- **Audience and task:** Help Nigerian viewers quickly find Netflix categories by genre, mood, keyword, or code, then open the category on Netflix.
- **Direction:** Consumer entertainment discovery with clear search, visible filters, and scannable category results. Use JustWatch as a reference for discovery structure only; do not copy its branding, wording, or exact layout.
- **Results pattern:** Use the user's supplied screenshot as a UX reference for a prominent search field, result count, favourites-only control, and compact category rows with a save action and clear copy/open buttons. Keep Wachoo's own content and visual identity.
- **Mood discovery:** Add a clear mood prompt followed by six large, selectable mood shortcuts. Use the supplied Nigerian-English heading and supporting line as approved copy; keep mood-to-category mappings editorial.
- **Brand:** Keep the supplied Wachoo logo and the approved identity from the product brief. Use Plus Jakarta Sans.

## Color and themes

- **Dark theme is the default:** Deep Green `#081F1C` background, layered dark-green surfaces, Soft White `#F8FAF8` text.
- **Light theme:** Soft White `#F8FAF8` background, dark-green text, and neutral `#E5E7EB` surfaces.
- **Shared accents:** Wachoo Green `#00D6BF` for primary actions and focus; Vibe Lime `#C7F464`, Warm Coral `#FF6B4A`, and Cinema Purple `#7861FF` for supporting emphasis.
- Provide a clear theme switch. Pair status or meaning with text and never rely on color alone. Theme preference persistence is not yet specified.

## Layout and interaction

- Put category search and mood discovery near the top of the page; keep filters easy to find and clear.
- Present mood shortcuts in a responsive grid; use emoji as decorative cues paired with readable text labels and keyboard-operable buttons.
- Show the result count and favourites-only control before the list. Each readable category row shows its name, useful parent or mood context, code, save control, and copy/open actions.
- Order officially mentioned or directly checked codes first, followed by other collected codes. Do not show an “unverified” label; keep source and verification information in the data for maintenance.
- Design for desktop, tablet, and mobile with readable spacing, keyboard access, visible focus, and clear loading, empty, and error states.
- Respect reduced-motion preferences; use animation only when it helps people understand an interaction.

## Product-specific detail

Use Wachoo’s category codes and mood-based discovery as the recognizable product element, with the supplied logo and “Find it. Watch it. Love it.” identity.
